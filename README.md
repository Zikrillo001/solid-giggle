# Mening birinchi saytim 🚀

## Vazifalar

Har bir vazifadan keyin **commit** qil (o'zgarishni saqla) va qisqa xabar yoz.

- [ ] 1. `index.html` faylida ismingni yoz → commit: `Ismimni yozdim`
- [ ] 2. Emojini o'zgartir → commit: `Emoji o'zgardi`
- [ ] 3. Sevimli narsalaring ro'yxatiga yana bitta `<li>` qo'sh
- [ ] 4. `style.css` faylida fon rangini o'zgartir
- [ ] 5. Tugma rangini o'zgartir
- [ ] 6. `script.js` faylida salom xabarini o'zgartir
- [ ] 7. Ranglar ro'yxatiga o'z rangingni qo'sh
- [ ] 8. **History** (tarix) bo'limini och va barcha commitlaringni ko'r 🕒
- [ ] 9. Saytingni GitHub Pages orqali internetga chiqar va linkni ota-onangga yubor! 🌍
